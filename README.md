# Zulu Logistics Leads Hunter

Internal lead tool for the Zulu Logistics sales team. Pulls new carrier authorities live from FMCSA public data (data.transportation.gov).

Live at https://leadhunter.zululogisticshub.com (GitHub Pages).

**Releasing an update:** replace `index.html`, bump `APP_VERSION` inside it and the same value in `version.json`. Open copies show an "update available" banner within ~5 minutes.
